## 1. 研究定位

### 1.1 任务定义

**设定**：静态环境 E（无先验地图或可选先验），其中划定搜索区域 R ⊂ E。四旋翼搭载 RGB-D 相机与机载计算，无 GNSS 依赖。

**输入**：自然语言查询 Q（开放词汇，如 "red car"、"yellow tent"），描述目标物体；目标位于 R 内未知位置。

**观测与决策**：每时刻 t 机体获得观测 O_t = {I_t, D_t, x_t}（RGB、深度、位姿/机体状态），按策略 π: O_t ↦ a_t 执行动作，状态转移至 x_{t+1}。

**任务**：自主搜索区域 R，找到 Q 描述的目标物体并输出其三维位置估计 p̂_goal。

**成功判据**：机体对目标完成置信确认（深度锁定）并在目标膨胀区外停住，且上报位置满足 ‖p̂_goal − p_goal‖ < ε_loc。

**目标函数**：最小化期望搜索代价

J(ξ) = 𝔼_E [ Σ_{t=0}^{T−1} C(x_t, a_t, x_{t+1}) ]

其中 C 综合飞行时间、路径长度与安全约束；期望取于未知环境分布；受机载算力与局部规划时域 H ≪ T 约束。

**备注（巡检作为特例）**：预定义路线巡检（"沿途是否存在某物"）是本框架的退化情形——把巡检路线视为宽度趋近于零的走廊形区域，耕地扫掠的预生成路线在窄走廊中即巡检路线本身。论文以区域搜索为主设定（贡献完整），巡检场景可作应用演示（一组 episode 即可），系统、接口、网络均无需改动。

### 1.2 创新点

**1. 区域开放词汇目标搜索系统。** 面向"在指定区域内定位文本描述的目标"这一任务，给出搜索、检测、接近、确认、否决的完整状态机。检测过阈立即中断扫掠；单条方位射线已经给出目标方向，接近不必等待假设成熟；绕障带来的侧向视差让三角化在接近途中自然完成；假设被否决后就地重选 frontier，无需折返中断点。目标允许不可达（建筑物本身就是典型情形），成功判据取悬停确认与上报位置的精度。

**2. 引力斥力场任务接口。** 冻结的 SCLIP 把文本与 RGB 联合嵌入，输出 signed 冷暖热力图：热区吸引，冷区排斥，两者落在同一张图上，合力恰好把机体停在膨胀区外。热力图池化为 N×M primitive 网格后成为快规划器唯一的任务输入，不再设 goal 通道。扫掠与接近共用这个接口，状态切换只是场内容的更新，快回路在任何时候看到的都是同一种信号。

**3. 任务感知代价引导的训练方法与数据协议（本文主贡献）。** 感知与规划解耦：开放词汇能力全部由冻结的 VFM 零样本承担，规划器只学习向暖、避冷、绕障、不越出 R_plan 这四条几何规则，与类别无关，训练数据也因此不需要语义成对标注。从深度对应的 ESDF 或可见图中取真实可达节点投影成引力分数，不可行与已访问节点记负；同一帧深度可以配许多组不同分数，构成反事实样本。这种做法一举三得：数据量组合放大；网格成为唯一携带答案的通道，融合层无法抄几何捷径将其忽略；"引力穿墙"（目标在楼后或楼内）的情形也被覆盖。监督信号由解析代价公式直接给出，不必运行专家规划器。训练分三步走：先训无语义基座，再冻结主干单训融合层，最后端到端微调。真实 RGB-D 只用于校准 τ_low、τ_confirm 与归一化温度，校准与测试采用不相交的查询集合，开放词汇泛化由此可以干净地归因于表示设计而非数据记忆。

**4. 在线记忆与全局决策。** 双层格网维护节点得分：检测射线的 ε 走廊累积证据，途经观测为空的节点随即清零，连通的高分节点聚合为实例假设，被否决的假设衰减移除。格网在线增删，剔除分静态永久与动态超时两级。frontier 按 signed 得分减路径代价排序，Dijkstra 以 1 Hz 周期重规划。这一决策结构对应在线 orienteering 问题类，评估时对照离线全知最优给出竞争比。

### 1.3 相关工作与区分

**(a) 开放词汇视觉感知。** CLIP（Radford et al., ICML 2021）建立了图像级开放词汇能力；将其稠密化用于分割的 training-free 路线包括 SCLIP（ECCV 2024，相关自注意力）、NACLIP（WACV 2025，邻域感知注意力）、CLIPtrase（ECCV 2024）、PEARL（Pei et al., 2026，几何对齐语义）。**本文直接采用冻结 SCLIP 作感知前端，贡献不在编码器**，而在两点：signed 冷暖场的构造（固定负查询集 → 障碍排斥项，目标吸引与障碍排斥同图表达）；稠密热力图向 primitive 规划接口的池化投影。

**(b) 视觉-语言导航与目标搜索。** VLFM（Yokoyama et al., ICRA 2024）用 VLM 余弦相似度构建值图选择 frontier，室内地面 ObjectNav：每帧单一分数、无排斥项、无假设管理、检测到目标后直接导航过去，无主动确认。WildOS（Shah et al., 2026）是最接近的工作：稀疏导航图＋ExploRFM（RADIO 基座，需在标注数据上微调）对 frontier 节点打分，粒子滤波实现超深度量程目标粗定位，野外地面机器人验证。**与 WildOS 的区别**：① 任务条件的作用层不同——WildOS 给图节点打分（决定"去哪"），本文把引力斥力场注入学习式快规划器的代价头（决定"怎么飞"，轨迹级 shaping）；② ExploRFM 需要标注数据训练，本文感知全程冻结免训练；③ 本文有检测中断—接近—确认/否决状态机与方位射线证据计分（ε 走廊、图动态增删、途经核查），WildOS 的图仅维护 frontier 评分；④ 平台：地面低速越野 vs 四旋翼高速三维。任务设定层面，本文以指定区域＋覆盖义务替代其操作员先验方位 g₀，成功判据为悬停确认＋定位精度（允许目标不可达，如建筑物）而非进入目标可达距离 d_reach。

**(c) 超深度量程的语义建图。** RayFronts（Alama et al., 2025）在占据地图 frontier 上挂语义射线，支持对范围外区域的开放集查询，但它是**建图表示**，论文明确将规划集成留作 future work。本文的方位射线不是地图表示而是**在线检测证据**（ε 走廊计分、实例关联、三角化），且不维护稠密语义地图——快回路 map-free，慢回路只保留稀疏格网。

**(d) 学习式规划器。** YOPO（FAST Lab, T-RO 2025）：深度＋机体状态＋goal 向量 → 候选轨迹＋代价，guidance learning 单阶段训练，任务无关。YOPO-Rally（Lu et al., 2025）：地面越野扩展＋Unity YOPO-Sim，行为克隆。LRN（Schmittle et al., CoRL 2025）：从无标注第一视角视频学习 affordable frontier 热力图、按航向选方向，突破局部地图时域，但 goal 是航向向量（非语言查询）、无记忆、地面平台。**本文**：goal 向量升级为引力斥力 primitive 场，任务感知代价条件化＋反事实配对训练协议＝主贡献；感知—规划解耦使开放词汇能力零训练成本获得。

**(e) 搜索理论谱系。** frontier 探索（Yamauchi, 1997）、NBV、Bayesian optimal search（Stone, 1975）、orienteering/TSP with profits——本文的决策结构对应在线 orienteering 问题类（见 1.2）。

**速查表**：

| 方法 | 感知 | 任务条件作用层 | 平台 | 与本文关系 |
|---|---|---|---|---|
| VLFM | BLIP-2 冻结 | frontier 选择（值图） | 室内地面 | 单分无排斥，无主动确认 |
| WildOS | ExploRFM 需训练 | 图节点打分（去哪） | 野外地面 | 最接近；本文作用于轨迹代价（怎么飞） |
| RayFronts | 自训练编码器 | 不涉及（建图表示） | 通用 | 本文射线＝在线证据而非地图 |
| LRN | SAM2＋视频自标注 | 方向选择（航向） | 地面 | 无语义查询、无记忆 |
| YOPO/-Rally | 深度（无语义） | goal 向量 | 四旋翼/地面 | 本文基座；goal→引力斥力场 |

### 1.4 平台选择：四旋翼

- YOPO 血统即四旋翼规划器，代价 shaping 在高速飞行中体现最充分；
- 三角化需要三维侧向视差，地面平台几何退化；
- 悬停确认零代价（地面车有非完整约束）；
- 与 YOPO-Rally 形成地面/空中分工。
- 机体尺度参数化：膨胀半径、动力学约束、规划半径、深度量程随尺度调整，结构不变（可做大小尺度泛化实验）。

## 2. 系统架构（快慢双系统）

```
观测输入：RGB-D / 文本查询 Q / 机体状态 / 先验地图(可选)

慢系统（~1 Hz，控制回路外）
  ① 语义感知：SCLIP 冻结骨干（文本＋RGB 联合嵌入）
       → signed 冷暖热力图 H(x) = sim(x, Q) − sim(x, 负查询集)
       → 池化为 N×M primitive signed score
  ② 记忆与全局决策：覆盖格网＋节点得分＋frontier＋动态图增删
       → 在线 orienteering 排序（Dijkstra 8 连通）
       → 引力斥力场合成＝语义热 ⊕ frontier 吸引 ⊖ 几何/语义斥力

快系统（控制回路内）
  ③ YOPO 单次前向：(深度, 机体状态, 引力斥力网格) → 候选轨迹＋代价 → 最优轨迹执行
```

### 2.1 接口定义（全部接口，无 goal 通道）

| 接口 | 方向 | 内容 |
|---|---|---|
| 引力斥力网格 | 慢→快 | float32，N×M（默认 5 方位列×3 俯仰行，分辨率是可调超参），signed ∈ [−1,1]，机体视场对齐。**唯一任务接口** |
| 深度 | 输入→快 | 直送 YOPO，不建图 |
| 机体状态 | 输入→快 | 速度、姿态等 |
| 状态反馈 | 快→慢 | 位姿、已访问节点标记、深度锁定标志 |
| 先验地图（可选） | 输入→慢 | 初始化膨胀区/格网 |

**设计要点**：扫掠与接近共用同一接口，状态切换只是引力斥力场内容的更新（1 Hz），快系统接口恒定，不存在底层控制器切换不连续。

### 2.2 signed 冷暖热力图

- H(x) = sim(x, 目标查询) − sim(x, 负查询集)；负查询集＝通用障碍概念（"obstacle"、"wall"、"tree" 等），固定；
- 热（正）＝目标吸引，冷（负）＝障碍排斥；单次前向，训练-free；
- 该表示自然化解"目标本身是建筑"的矛盾：热说"去"，冷说"别撞"，合力即膨胀区外悬停；
- 归一化温度/尺度系数需校准（SCLIP 原始相似度绝对值随查询漂移）。

## 3. 状态机

**搜索（耕地扫掠）→ 检测 → 接近 → 确认／否决**

1. **搜索**：沿预生成 boustrophedon 路线覆盖；避障用**可见图**绕行（路径只经过膨胀区顶点）；慢系统周期更新节点得分、动态图增删、frontier 排序（signed 得分 − λ·路径代价，在线 orienteering 贪心），将 frontier 方向编码为引力。
2. **检测**：SCLIP 热度超 τ_low（几帧确认滤误检）即**当场中断扫掠**。单条方位射线＝方向已知、距离未知；goal 接口只需方向，因此无需等待假设成熟，立即进入接近。
3. **接近**：射线方向编码为引力（soft 分布）；绕障走 8 连通格网斜边；沿途新位姿检测持续更新得分（ε 走廊正证据、途经节点观测为空→清零）；绕障产生的**侧向视差**使两条射线交叉，三角化收敛（接近与三角化是同一过程）。
4. **确认**：深度锁定目标（τ_confirm），膨胀区外停住，上报**射线交点**位置（连续坐标，不受格网分辨率限制）。
5. **否决**：走近后无复检→得分衰减→**就地**重选 frontier 续扫（不返回中断点，沿途节点已核查更新）。

## 4. 记忆与全局决策

### 4.1 节点得分（计数器，五条规则）

1. **正证据**：检测射线 ε 走廊内节点 +1（可选相似度加权）；
2. **负证据**：途经/观测为空节点清零（"途经即核查"）；
3. **聚合**：连通高分子图＝一个实例假设（多实例关联）；位置＝射线交点（连续）；
4. **衰减**：被否决假设随时间衰减至移除；
5. **双层格网**：导航层剔除膨胀区节点；假设层保留完整格网（目标可在障碍 footprint 内，如 "red building"）。

得分用途：检测↔实例关联；假阳性抑制（单帧误检永远得不到第二条交叉射线）；最终上报位置来自射线交点而非节点。

**射线裁剪规则**：ε 走廊对已知占用格（先验地图或累积深度）做可见性检查，墙后节点不计分。

### 4.2 动态图增删（在线）

- **节点＋**：初始格网；临时目标节点（规划期）；
- **节点−**：膨胀剔除（静态永久/动态超时恢复）；否决衰减至零移除；
- **边＋/−**：可见性检查（线段与膨胀多边形求交）；障碍切断边（同样分静/动两级）；
- 8 连通（斜边合法，代价＝欧氏长度×得分因子，斜边 √2·s），可选 shortcut 平滑。

### 4.3 引力斥力场合成

引力斥力网格＝语义热 ⊕ frontier 吸引 ⊖ 几何/语义斥力，合成在慢系统：

- 无语义信号时 frontier 吸引主导；检测确认后目标引力接管（按得分加权或硬优先）；
- 方向编码用 **soft 分布**：按方位角对相邻 2~3 栅格高斯加权，质心编码亚栅格方向（N×M 每格约 30°，one-hot 量化误差不可接受）；
- **俯仰行数 ≥3**（默认 5 列方位×3 行俯仰）：承载"飞越 vs 下钻"决策；压成单行后楼上方翻越与侧向绕行不可区分；
- 斥力分工：近场障碍由 YOPO 原生深度避障处理；网格斥力承载语义排斥与超深度量程的几何排斥（先验/累积已知障碍）。

## 5. 观测性与视差（论文要点）

沿射线纯直线接近时，两个检测位姿共线，三角化无法收敛；绕障 detour 天然提供侧向视差，使射线交叉。无障碍时需主动侧向偏移。这是一个可写入论文的观测性分析点：接近路径规划应偏好带横向视差增益的路线（或将其纳入代价）。

## 6. 训练方法与数据协议（主贡献）

### 6.1 解耦原则

```
文本 + RGB → 冻结 VFM(SCLIP) → signed 热力图 → 固定池化 → primitive signed score
                                                                    ↓
                              Depth + signed score + state → 语义条件轨迹规划器
```

规划器**不学习类别**（person、red building 等），只学习四条 primitive 规则：

1. 暖的方向优先；
2. 冷的方向避开；
3. 深度中有障碍时生成绕行轨迹；
4. 局部轨迹不超过 R_plan。

开放词汇泛化完全由冻结 VFM 零样本承担；规划侧的 sim2real 语义差距为零。

### 6.2 反事实配对（核心数据技术）

不需要"文本目标＋RGB-D＋正确热力图＋轨迹"的成对数据。复用已有深度帧：

1. 从该帧 ESDF/可见图中选真实可达节点，投影到 primitive 网格→引力分数（soft 分布）；
2. 不可行、已访问节点编码为负分；
3. **同一 Depth 配多组不同分数**＝反事实训练样本。

作用：① 数据量组合放大；② **防止通道忽略**——若引力总与几何可行方向共现，融合层可学会忽略网格通道；反事实配对使网格成为唯一判别信号；③ 覆盖"引力穿墙"（目标在楼后/楼内）情形，网络学到"绕行接近"而非"直线撞墙"。

### 6.3 解析代价监督（无专家规划器）

YOPO 输出候选轨迹的代价，标签解析计算：碰撞项（查几何真值）＋引力对齐项（轨迹方向 vs 引力方位）＋斥力侵入项（轨迹 vs 冷斑）＋平滑/动力学项。无需最优规划器求解，数据全自动生成。

### 6.4 分阶段训练

| 阶段 | 训练 | 冻结 | 数据 |
|---|---|---|---|
| 0 | 无语义基座（深度＋状态→轨迹代价） | 网格分支不存在 | 程序化障碍世界（可直接 warm start yopo-simple 权重） |
| 1 | 网格融合层（小） | Stage 0 全部 | 深度＋反事实 primitive 分数，解析标签 |
| 2 | 全部解冻，低学习率联合微调 | 无 | 同 Stage 1，混入少量真实校准网格 |

VFM 全程冻结，不参与规划训练。

### 6.5 真实数据仅用于校准（不用于端到端监督）

- 校准对象：τ_low、τ_confirm、热力图→primitive 分数的归一化温度；
- 规模：几千帧级，一次性离线采集；
- 查询协议：校准用查询集合 A，测试用**与 A 不相交**的查询集合 B（含未见类别），证明开放词汇泛化来自表示设计而非数据记忆。

### 6.6 引力斥力图的可选蒸馏

冻结 SCLIP 在运行时已是单次前向（负查询集固定）。若需机载部署压缩，可自蒸馏：教师＝冻结 SCLIP，学生＝轻量文本条件分割头（CLIP 文本嵌入＋图像特征→signed 图），标签由教师在仿真中对任意采样查询自动生成；学生经文本嵌入接口继承开放词汇能力。属部署优化，不进论文主线（可作消融或 future work）。

## 7. 仿真与实验计划

### 7.1 仿真环境

- **主仿真**：Colosseum（AirSim 社区维护分支）＋ UE5 自建工程（插件拷入自有工程），场景内容完全可控（目标颜色/类别/摆放，分割实例 ID 自控→目标 GT 与评估标签自动生成）；
- **三张实验图**：① 城市楼群（密集高楼）；② 树林（树干级密集障碍）；③ 混合（楼群—树林过渡带，检验语义混杂区排斥/吸引平衡）；
- **批量训练**：轻量程序化仿真（随机障碍世界＋程序化/反事实 signed 网格）；Isaac Aerial Gym 作为 GPU 并行备选（其程序化环境生成器自带树林/楼块障碍类型）；
- 现成 AirSim 环境（CityEnviron、TrapCamera、LandscapeMountains 等）仅用于冒烟验证，场景不可编辑，不作正式实验。

### 7.2 查询矩阵（同图多查询，episode 复用）

| 类型 | 示例 | 考察点 |
|---|---|---|
| 纯类别 | "car"、"tent" | 类别级语义定位 |
| 属性＋类别 | "red car"、"yellow truck" | 属性绑定，硬干扰物判别 |
| 罕见/组合 | "white van"、"blue container" | 开集泛化 |

每图配 5~10 个查询，含语义相似干扰物；测试查询与校准查询不相交（集合 A/B 协议）。

### 7.3 基线与消融

**基线**：原始 YOPO（无语义）＋frontier；WildOS 式静态打分图一次性 Dijkstra；经典 frontier/NBV＋检测器。

**消融**：
1. 训练三档（无语义基座／冻结＋融合层／端到端微调）；
2. 网格分辨率（1×5、3×5、5×3、更细）与 soft/one-hot 编码；
3. 反事实配对有无（检验通道忽略）；
4. 合成网格 vs 真实 SCLIP 网格训练；
5. τ 校准有无；
6. A/B 查询泛化（开放词汇证明）；
7. 大小尺度机体（同一权重，膨胀/动力学参数化）。

### 7.4 指标

成功率（确认并上报）、平均搜索时间、路径长度、定位误差（上报点 vs GT）、假阳性率、**竞争比**（vs 离线全知最优）、动力学可行性、防摇摆（假设切换次数）。
