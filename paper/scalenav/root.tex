\begin{abstract}
A reactive flight policy can avoid nearby obstacles, but it cannot retain a
detour around a wall or react to semantic risk beyond valid depth.
We present ScaleNav, a hierarchical planner that adds semantic foresight to an
unchanged neural local planner.
The slow layer maintains a bounded, persistent free-space topology directly
from depth point clouds.
A frozen open-vocabulary model supplies sparse image-space risk observations.
Valid observations update measured graph nodes.
Depth-clipped observations become persistent far-field semantic nodes.
Each node induces a continuous risk field over collision-free edge witness
paths, so a route can change before the vehicle reaches the risky endpoint.
Semantic risk changes route preference but never changes geometric validity.
The selected witness path is stored in world coordinates and remapped after
asynchronous graph replacement.
This preserves route identity without retaining stale node pointers.
A rolling local goal is then sent to the original YOPO interface, which still
uses one depth channel and a 9-D motion-and-goal state.
Thus, the method adds long-horizon memory and open-vocabulary intent without
retraining the local policy, constructing an occupancy grid, or building an
ESDF.
We define controlled simulation and system experiments for topology, semantic
foresight, route stability, safety, and runtime.
We also specify two planned extensions: a corridor-conditioned YOPO interface
and a model-agnostic semantic adapter that can replace PEARL with Qwen3-VL.
These extensions are separated from the implemented claims.
All result fields are intentionally left blank pending evaluation.
\end{abstract}

\section{INTRODUCTION}
A small aerial robot must solve two different planning problems at once.
It must react to branches and narrow gaps within the current depth image.
It must also remember which side of a large obstacle leads toward a distant
goal.
The first problem needs a fast local policy.
The second needs persistent spatial structure.

One-stage neural planners such as YOPO \cite{yopo} are effective local motion
generators.
They map depth, motion state, and a relative goal to short trajectories.
Their horizon, however, is limited by the sensor and their current input.
A long wall can force an early left-or-right decision whose consequence is not
visible in one frame.
Open-vocabulary perception creates a second horizon mismatch.
An RGB model may recognize a risky structure where depth is clipped, but a
reactive collision policy has no stable place to store or use that evidence.

ScaleNav addresses both mismatches at the route level.
It converts depth into a persistent graph of free-space regions and
collision-checked witness paths.
It converts open-vocabulary image evidence into a continuous cost field on
that graph.
The output is only a rolling 3-D goal for the local planner.
The deployed YOPO network, its weights, its depth input, and its 9-D state
interface are unchanged.

The unusual part of the design is where semantics acts.
We do not classify a graph edge as safe or unsafe.
We also do not send a heatmap into the neural policy.
Instead, a depth-clipped semantic ray creates a far-field semantic node at a
fixed optical depth.
The distance from this node to every nearby edge witness defines a smooth
repulsive field.
Ordinary free-space edges become expensive before the node itself is
reached.
This lets the route choose the opposite branch early.
At the same time, the geometry layer remains solely responsible for collision
validity.
A semantic error can select a poor route, but it cannot certify an occupied
edge as free.

The graph is rebuilt asynchronously as new depth arrives.
This makes route persistence nontrivial: node addresses and local clusters can
change while the physical corridor stays the same.
ScaleNav stores the selected witness polyline in world coordinates.
It remaps a forward window of this polyline to the new topology and applies a
soft cost prior.
New semantic evidence can still release the prior when route risk changes.

Our contributions are:
\begin{itemize}
  \item \textbf{Semantic foresight on free-space topology.}
  We formulate open-vocabulary evidence as a continuous risk field over edge
  witness paths. Semantics changes long-horizon branch preference, while
  geometric collision checking remains independent.
  \item \textbf{Far-field semantic nodes.}
  We turn depth-clipped semantic rays into bounded, graph-connected
  hypotheses at a fixed optical depth. They influence nearby ordinary edges
  before direct depth is available and are promoted to verified geometry as
  real bubbles reach them.
  \item \textbf{Persistent route identity under graph replacement.}
  We preserve a route as a world-frame witness path and remap it after each
  incremental update. This reduces branch oscillation without freezing the
  topology or keeping stale pointers.
  \item \textbf{A policy-preserving hierarchy.}
  The graph sends a rolling goal to the original single-depth-channel YOPO
  runtime. Long-horizon memory and language-conditioned guidance require no
  local-policy retraining and no occupancy grid or ESDF.
\end{itemize}

Two further innovations are designed but not yet implemented.
First, the selected route can be rendered as a depth-aligned corridor and sent
to YOPO, increasing the memory interface from one waypoint to a spatial region.
Second, the semantic front end can obey a common risk contract, so a larger
model such as Qwen3-VL can replace PEARL without changing graph search.
Section~\ref{sec:extensions} defines both interfaces.

\section{RELATED WORK}
\subsection{Local Reactive Flight}
Depth-based reactive planners trade global consistency for low latency.
RAPPIDS partitions a single depth image into rectangular pyramids and tests
candidate trajectories against them \cite{rappids}.
NanoMap keeps a short history of raw range measurements and answers
uncertainty-aware proximity queries without fusing a global map
\cite{nanomap}.
EGO-Planner removes the ESDF from the local optimization loop
\cite{egoplanner}, and learned policies collapse sensing, search, and
optimization into a single network pass \cite{yopo,loquercio}.
All of these methods decide motion from what is visible now:
nothing in their state remembers which side of a distant wall was chosen
seconds earlier, and nothing in their input accepts semantic intent.
ScaleNav therefore keeps such a policy unchanged as its fast layer and adds
memory and semantics around it rather than inside it.

\subsection{Persistent Free-Space Structure}
A second line of work builds structure that outlives one sensor frame.
FUEL maintains frontier information incrementally and plans hierarchically
for fast exploration \cite{fuel}.
FAR Planner updates a global visibility graph as obstacles are observed
\cite{far}, and Bubble Planner extends receding safe corridors for
high-speed flight \cite{bubble}.
EPIC clusters free-space spheres from point clouds into a lightweight
topology for large-scale exploration \cite{epic}.
These structures are geometric: their costs encode distance or information
gain, so a text query such as ``avoid the crowd'' has no representation.
ScaleNav reuses the EPIC-style free-space representation but solves a
different problem.
It performs goal-directed rolling search, preserves a selected witness
route across asynchronous graph replacement, and lets edges carry
open-vocabulary risk while geometric validity remains unchanged.

\subsection{Open-Vocabulary Perception and Semantic Navigation}
Open-vocabulary models supply image evidence beyond a fixed label set.
CLIP aligns image and text embeddings \cite{clip}, and PEARL produces
training-free open-vocabulary segmentation aligned with image geometry
\cite{pearl}.
On the planning side, VLFM builds vision-language value maps to select
frontiers for object navigation \cite{vlfm}, and RayFronts encodes open-set
semantics on both mapped voxels and beyond-range rays for online
exploration \cite{rayfronts}.
These systems bring semantics into the map or the frontier score, but the
map itself is the product; how a route should bend around a risky region
before the sensor reaches it is left to a separate decision layer.
ScaleNav targets exactly this interface: sparse image-space observations
become persistent costs on free-space edges, including evidence whose depth
is clipped, while collision validity remains purely geometric.

\section{PROBLEM FORMULATION}
Let the vehicle state at time $t$ be
$\vect{x}_t=(\vect{p}_t,\vect{v}_t,\vect{a}_t,\vect{R}_t)$.
The sensors provide an RGB image $I_t$, a planar-depth image $D_t$, and
odometry.
The mission gives a world-frame goal $\vect{g}$ and a text query $q$ that
describes regions to avoid.
No prior geometric map is available.

The planner must output a dynamically feasible local trajectory $\tau_t$.
We separate this problem into a slow route decision and a fast motion
decision:
\begin{align}
  \vect{g}^{\mathrm{loc}}_t
    &= \Pi_{\mathrm{topo}}(\mathcal{G}_t,I_{0:t},D_{0:t},q,\vect{g}), \\
  \tau_t
    &= \Pi_{\mathrm{local}}(D_t,\vect{v}_t,\vect{a}_t,
       \vect{R}_t^\top(\vect{g}^{\mathrm{loc}}_t-\vect{p}_t)).
\end{align}
In the current system, $\Pi_{\mathrm{local}}$ is the released YOPO runtime.
Its input remains one $160\times96$ depth channel and
\begin{equation}
 \vect{o}_t = [\vect{v}^{B}_t,\vect{a}^{B}_t,
                (\vect{g}^{\mathrm{loc}}_t-\vect{p}_t)^{B}] \in \R^9.
\end{equation}
Only $\Pi_{\mathrm{topo}}$ is introduced by ScaleNav.

We use a fixed-height planning layer in the current experiments to isolate the
horizontal branch-selection problem.
The depth sensing, point memory, and local trajectory execution remain 3-D.
The proposed semantic cost is defined on 3-D witness polylines and does not
require the fixed-height assumption.

\section{PERSISTENT FREE-SPACE TOPOLOGY}
\label{sec:topology}
\subsection{Bounded Geometric Memory}
Depth is back-projected into obstacle points and free-ray evidence.
The implementation voxel-filters this stream and retains at most $N_{\max}$
points within a radius $R_m$ of the vehicle.
It does not construct occupancy voxels or an ESDF.

Following EPIC \cite{epic}, collision-free bubbles are clustered into graph
vertices.
A vertex is
\begin{equation}
 v_i=(\vect{c}_i,\rho_i,z_i,h_i),
\end{equation}
where $\vect{c}_i$ is its center, $\rho_i$ is free-space clearance, $z_i$ is
semantic state, and $h_i$ is a persistent identity record.
An edge stores a collision-checked witness polyline
\begin{equation}
 \pi_{ij}=\{\vect{w}^{ij}_0,\ldots,\vect{w}^{ij}_{M_{ij}}\},
 \quad
 L_{ij}=\sum_{m=1}^{M_{ij}}
 \|\vect{w}^{ij}_m-\vect{w}^{ij}_{m-1}\|_2.
\end{equation}
The witness is important twice.
It is the executable geometric connection, and it is the support on which
semantic distance is measured.
The chord $\vect{c}_j-\vect{c}_i$ is insufficient because a valid witness may
bend around an obstacle.

Geometry is updated in a background graph.
After local bubble generation, region clustering, and graph connection, an
atomic swap exposes the new graph to planning.
The point budget and spatial radius bound memory.
Transiently missing bubbles receive a short grace period before deletion.

\subsection{Clearance-Aware Edge Cost}
Let $\rho_{ij}=\min(\rho_i,\rho_j)$ and let $\rho^\star$ be the target
clearance.
The implemented soft clearance term is
\begin{equation}
 C_{\mathrm{clr}}(e_{ij})=
 \lambda_{\mathrm{clr}}L_{ij}
 \left[
 \max\left(0,\frac{\rho^\star-\rho_{ij}}{\rho^\star}\right)
 \right]^2.
\label{eq:clearance}
\end{equation}
It prefers open routes but does not declare a narrow valid edge invalid.
Geometric feasibility remains determined by the bubble graph and its witness
checks.

\section{SEMANTIC FORESIGHT}
\label{sec:semantics}
\subsection{Semantic Observation Model}
The frozen PEARL model maps $(I_t,q)$ to a patch heatmap.
The heatmap is max-pooled on a $5\times3$ grid, and a low-quantile
background baseline is subtracted so that weak whole-image responses do not
become risk.
Every retained patch is projected by the calibrated pinhole model at a fixed
optical depth $\ell_s$, independent of the measured depth:
\begin{equation}
 \vect{y}_{u,t}=\vect{o}_t+\ell_s\,\vect{d}_{u,t},
\label{eq:projection}
\end{equation}
where $\vect{o}_t$ is the camera origin and $\vect{d}_{u,t}$ is the unit ray
of patch $u$.
Depth clipping therefore never blocks semantic evidence; it only fixes the
range at which the evidence is placed.
For a graph node $v_i$, the associated observation is
\begin{equation}
 \hat{s}_{i,t}=
 \max_{u:\|\vect{y}_{u,t}-\vect{c}_i\|\le r_a}
 s_{u,t}
 \exp\left(-\frac{\|\vect{y}_{u,t}-\vect{c}_i\|^2}{2\sigma_a^2}\right).
\label{eq:association}
\end{equation}
An exponential moving average removes single-frame score jumps:
\begin{equation}
 s_{i,t}=(1-\alpha)s_{i,t-1}+\alpha\hat{s}_{i,t}.
\label{eq:ema}
\end{equation}
The tuple $(s_i,c_i)$ denotes the stored score and confidence.
It is restored by persistent node identity after graph replacement.
Four evidence factors---multi-row consistency, FOV margin, suspected ground
response, and observation freshness---modulate the confidence instead of
rejecting observations outright.

\subsection{Far-Field Semantic Nodes}
Each projected point $\vect{y}_{u,t}$ becomes a persistent graph node with
unknown geometry state and a semantic score.
Repeat observations within $r_m$ update the same node through
(\ref{eq:ema}), and overlapping fields of view across frames re-use the same
persistent identity through ray association.
The node set is bounded by a maximum count, a minimum score, and a minimum
mutual separation, and nodes do not expire with time.
Semantic nodes are stored with the global graph and survive the sliding
geometric window; risk queries touch only nodes inside the local planning
radius plus an influence band.
Each node is connected through the same local graph machinery as geometric
nodes.
When measured geometry later grows a bubble at the node's position, the node
is promoted from unknown to verified while its semantic identity is
retained.

A far-field semantic node is not a hard obstacle.
It is a hypothesis about route risk beyond valid depth.
This distinction lets low-risk clipped rays remain useful as forward graph
hypotheses while high-risk rays repel the selected route.

\subsection{Continuous Risk on Witness Paths}
Endpoint-only node costs react too late.
A risky semantic node may sit beyond a fork while neither endpoint of the
fork has a high semantic score.
We therefore measure every semantic node against the complete witness
polyline:
\begin{equation}
 d_{k,ij}=\min_{\vect{x}\in\pi_{ij}}
             \|\vect{y}_k-\vect{x}\|_2.
\label{eq:anchor_distance}
\end{equation}
The measured endpoint risk is
\begin{equation}
 r^{\mathrm{node}}_{ij}=\frac{1}{2}(s_i c_i+s_j c_j).
\end{equation}
Semantic node $k$ induces the edge risk
\begin{equation}
 r^{\mathrm{ff}}_{k,ij}=s_kc_k
 \exp\left(-\frac{d_{k,ij}^2}{2\sigma_s^2}\right),
 \qquad d_{k,ij}\le R_s.
\label{eq:field}
\end{equation}
The combined risk uses a maximum rather than a sum:
\begin{equation}
 r_{ij}=\max\left(r^{\mathrm{node}}_{ij},
                  \max_k r^{\mathrm{ff}}_{k,ij}\right).
\label{eq:risk}
\end{equation}
This avoids making risk depend on the arbitrary density of nearby semantic
nodes.
The semantic edge penalty is the barrier
\begin{equation}
 C_{\mathrm{sem}}(e_{ij})=
 \lambda_{\mathrm{sem}}L_{ij}[-\log(1-r_{ij})].
\label{eq:semantic_cost}
\end{equation}
It is nearly linear at low risk and grows sharply near unit risk.
The factor $L_{ij}$ makes exposure accumulate with travel distance.

\section{RISK-AWARE ROLLING SEARCH}
\subsection{Edge and Path Objectives}
For an edge $e_{ij}$, the geometric traversal cost stored by EPIC is
$W_{ij}$.
Let $\kappa_{ij}=\kappa_{\mathrm{mem}}<1$ if the edge matches the remembered
forward route and $\kappa_{ij}=1$ otherwise.
The complete edge cost is
\begin{equation}
 C(e_{ij})=\kappa_{ij}W_{ij}
          +C_{\mathrm{clr}}(e_{ij})+C_{\mathrm{sem}}(e_{ij}).
\label{eq:edge_cost}
\end{equation}
For a graph path $P$, we separately accumulate its discounted geometric term
and its risk term:
\begin{align}
 G(P)&=\sum_{e\in P}\kappa_eW_e,\\
 R(P)&=\sum_{e\in P}
       \left[C_{\mathrm{clr}}(e)+C_{\mathrm{sem}}(e)\right].
\end{align}
Keeping them separate is important.
The terminal objective discounts geometry by a small factor, but must not
discount safety and semantic exposure.

The slow layer maintains three goal levels: the \emph{mission goal}
$\vect{g}$, a route-level \emph{frontier goal} selected inside the local
graph window of radius $R_g$, and a control-level \emph{local goal} on the
accepted witness.
The mission goal may lie outside the currently connected graph.
We therefore search all reachable non-viewpoint vertices within radius
$R_g$.
Terminal selection is a single soft loss: only disconnection, collision,
insufficient clearance, or a missing witness is a hard rejection.
For candidate $v$, let $d_{\mathrm{rsv}}(v)$ be the reserve shortage toward
the mission goal, $d_{\mathrm{dir}}(v)$ the misalignment with the mission
direction, $d_{\mathrm{fov}}(v)$ the offset from the field of view, and
$d_{\mathrm{sm}}(v)$ the heading discontinuity at the vehicle.
The implemented frontier-goal score is
\begin{align}
 J(v)={}&\alpha_gG(P_v)+R(P_v)
       +w_{\mathrm{rsv}}d_{\mathrm{rsv}}(v)+w_{\mathrm{dir}}d_{\mathrm{dir}}(v)
       \nonumber\\
       &+w_{\mathrm{fov}}d_{\mathrm{fov}}(v)
       +w_{\mathrm{sm}}d_{\mathrm{sm}}(v).
\label{eq:terminal}
\end{align}
Direction, FOV, and reserve terms guide the search but never disqualify a
feasible terminal; once the mission goal enters the local window, a bubble
search validates the final connection within a short range.
Graph A* uses $f=g+h$ with millisecond-scale connection budgets.
The best recovered path ends at
\begin{equation}
 v_t^\star=\arg\min_{v\in\mathcal{V}_{\mathrm{cand}}}J(v),
\end{equation}
and its terminal becomes the frontier goal.

\subsection{Route Identity Across Graph Updates}
Incremental graph replacement can change node objects even when the physical
route is unchanged.
ScaleNav therefore stores the selected witness in world coordinates:
\begin{equation}
 \mathcal{W}_{t-1}=\{\vect{w}_0,\ldots,\vect{w}_K\}.
\end{equation}
The vehicle is projected to this polyline and only a forward window of length
$H_r$ is retained:
\begin{equation}
 \mathcal{W}^{+}_{t-1}=
 \operatorname{crop}(\mathcal{W}_{t-1},
                     \operatorname{proj}(\vect{p}_t,\mathcal{W}_{t-1}),H_r).
\end{equation}
An edge in the new graph is remembered if its geometry follows this window
within a lateral tolerance.
The incumbent terminal is restored by persistent node identity first, with
nearest-neighbor remapping as a fallback.
Equation (\ref{eq:edge_cost}) then provides a soft prior rather than a hard
lock.

A challenger replaces the incumbent only through hysteresis: its risk must
improve by more than a margin, or its total cost must drop below a fixed
ratio of the incumbent cost.
A high-risk incumbent is latched until its route risk falls back below a
release threshold, and prefix-preserving route extensions are exempt from
the switch test.
The prior is released when the vehicle leaves the route or when semantic
risk along the route changes by more than $\Delta_r$:
\begin{equation}
 \left|\mathcal{R}(\mathcal{W}_{t-1};t)-
        \mathcal{R}(\mathcal{W}_{t-1};t-1)\right|>\Delta_r.
\end{equation}
This balance is central to the design.
Route memory prevents left-right oscillation.
Risk-triggered release lets new language evidence change the homotopy.

\subsection{Local Execution}
The graph concatenates the edge witnesses of the accepted route and selects
a point approximately $H_l$ meters ahead.
That point is published as the local goal $\vect{g}^{\mathrm{loc}}_t$ at a
fixed rate; if a replanning cycle fails, the last collision-free witness and
local goal are held for a bounded timeout instead of being dropped.
The local policy handles dynamics and immediate collision avoidance.
Semantics never changes the depth image, trajectory decoder, or controller.
This separation gives a clear failure boundary: the graph chooses where to
go, while YOPO decides how to move there.

\section{EXPERIMENTAL DESIGN}
\label{sec:experiments}
We specify the evaluation before collecting results.
No result in this section is inferred from development logs.
Every table cell marked ``--'' is reserved for measured data.

\subsection{Research Questions and Protocol}
The experiments answer eight questions.
Q1 asks whether persistent topology solves detours outside the local policy
horizon.
Q2 asks whether far-field semantic nodes cause an earlier correct branch choice.
Q3 asks whether continuous witness-field cost is better than endpoint-only
semantic cost.
Q4 asks whether route memory reduces branch switching without preventing a
valid semantic replan.
Q5 measures geometric safety and flight efficiency.
Q6 measures compute and memory cost.
Q7 asks whether a corridor improves local route adherence over a waypoint.
Q8 measures the semantic quality-latency tradeoff of PEARL, Qwen3-VL, and their
hybrid.

We use Colosseum/AirSim \cite{airsim} with synchronized RGB-D and odometry.
The current evaluation uses a 1.6-m horizontal graph layer.
Each condition uses at least 20 paired trials with identical starts, goals,
scenes, and random seeds across methods.
We report mean, standard deviation, and a 95\% confidence interval.
Paired continuous metrics use a two-sided Wilcoxon signed-rank test.
Success proportions use paired bootstrap intervals.
Failures remain in safety and success metrics and are not silently removed
from path-efficiency statistics.

\subsection{Methods and Ablations}
We compare:
\begin{itemize}
  \item \textbf{YOPO}: the original local planner with the mission goal.
  \item \textbf{Geometry}: persistent EPIC graph and rolling goal, with all
  semantic weights set to zero.
  \item \textbf{Measured}: geometry plus semantic memory on verified nodes.
  \item \textbf{Endpoint}: measured memory plus far-field semantic nodes, but
  semantics acts only at edge endpoints.
  \item \textbf{Field}: the full continuous witness-field method.
  \item \textbf{Field-NoMem}: full semantic field with route-memory discount
  disabled.
  \item \textbf{Field-NoRelease}: full field without semantic risk-triggered
  route release.
  \item \textbf{FAR}: FAR Planner \cite{far}, when the reproduced stack uses
  the same sensor range and local executor.
  \item \textbf{Corridor-YOPO (planned)}: the graph route is rendered with
  (\ref{eq:corridor_mask}) and added to the YOPO image input.
  \item \textbf{Qwen3-VL and Hybrid (planned)}: the semantic heatmap generator
  is replaced or augmented through (\ref{eq:semantic_contract}).
\end{itemize}

All ScaleNav variants share graph and local-policy parameters.

\subsection{Scenarios}
\textbf{Long-detour set.}
Walls and buildings vary in width, endpoint visibility, and approach angle.
The shortest valid side alternates across seeds.
This set tests whether the graph creates and keeps a route beyond depth range.

\textbf{Semantic-fork set.}
Both branches are geometrically valid.
The queried class lies beyond clipped depth on one branch.
We vary node score, lateral distance to each witness, time of first
observation, and whether later measured geometry verifies the node.
This isolates semantic foresight from collision avoidance.

\textbf{Contradiction set.}
A semantic update arrives after a geometric route has stabilized.
In half the trials it should trigger a branch change.
In the other half it lies outside the route influence radius and should not.
This tests both sensitivity and route stability.

\textbf{Mixed-scale set.}
A single flight contains open space, trees, narrow passages, and a building
detour.
No mode flag or parameter change is allowed during the run.

\textbf{Corridor-conflict set.}
The waypoint and final goal point through one branch, while the remembered
corridor bends into another branch.
Obstacle placement varies corridor width and introduces unexpected obstacles
inside the selected region.
This separates route-memory use from blind corridor following.

\textbf{Compositional-language set.}
Queries include simple categories, attributes, spatial relations, and
compositions such as ``avoid the red structure beside the tower.''
The scene contains hard negatives with the same category but different
attributes.
This set compares semantic accuracy against inference delay.

\subsection{Metrics}
Let the flight last $T$ with path $\vect{p}(t)$ and speed
$v(t)=\|\dot{\vect{p}}(t)\|$.
We report path length and average speed:
\begin{equation}
 L=\int_0^T v(t)\,dt,
 \qquad \bar{v}=\frac{1}{T}\int_0^T v(t)\,dt.
\end{equation}
Let $d_{\mathrm{obs}}(t)$ be distance to the nearest obstacle surface.
We report
\begin{equation}
 d_{\min}=\min_{t\in[0,T]}d_{\mathrm{obs}}(t),
 \qquad
 \bar{d}_{\mathrm{obs}}=\frac{1}{T}
 \int_0^T d_{\mathrm{obs}}(t)\,dt.
\end{equation}
Semantic exposure is
\begin{equation}
 E_{\mathrm{sem}}=\frac{1}{L}
 \int_0^T r(\vect{p}(t))v(t)\,dt.
\end{equation}
For semantic forks, decision distance is the along-track distance from the
vehicle to the fork when the selected route first enters and remains in the
correct branch for at least 2 s.
We also record route-switch count, success, collision, completion time,
normalized path length, maximum speed, and semantic task compliance.

System metrics are PEARL latency, graph-update wall time, A* latency, graph
node and edge count, resident memory, local-policy rate, and dropped semantic
frames.
We report medians and 99th percentiles for latency in addition to means.
For the planned extensions, we additionally measure corridor adherence,
unexpected-obstacle avoidance inside the corridor, semantic region precision,
semantic region recall, and stale-response rejection rate.

\subsection{Diagnostic Protocol}
Three focused tests make failures interpretable.
First, for each route edge we log $W_{ij}$,
$C_{\mathrm{clr}}$, $C_{\mathrm{sem}}$, and whether it matched route memory.
This identifies the exact term that selected a branch.
Second, we compare node-to-chord distance with node-to-witness distance.
The two differ on curved obstacle detours and directly test
(\ref{eq:anchor_distance}).
Third, we replay the same recorded RGB-D stream through all semantic ablations.
Geometry is then identical, so a branch difference can only come from the
semantic cost and route-release logic.

\section{DISCUSSION AND LIMITATIONS}
ScaleNav has a narrow and testable claim.
It adds route-scale memory and semantic branch guidance to an existing local
planner.
It does not replace the local planner's dynamic-obstacle response.
It also does not make semantics a safety certificate.

Far-field semantic nodes are deliberately optimistic geometry and uncertain
semantics.
A false positive can cause a longer route.
A false negative can remove the semantic advantage, after which the system
falls back to geometric topology and local depth avoidance.
The bounded Gaussian field and bounded node set limit the spatial effect of
either error, while EMA updates and confidence factors absorb temporal noise.

The current experiments simplify topological search to a fixed-height layer.
This prevents ground points from closing horizontal clearance and isolates the
left-right detour failure that motivated this work.
It does not evaluate vertical homotopy choices.
Future work should evaluate the same witness-field cost on a fully 3-D graph,
including over-under decisions and changing flight altitude.

The graph is not an occupancy grid, but it is still a spatial memory.
Its quality depends on depth coverage, odometry, and the EPIC bubble
construction.
The planned ablations therefore report graph connectivity and route-decision
timing, not only final flight success.

\subsection{Planned Extensions}
\label{sec:extensions}
The current executable system uses a rolling local goal and PEARL.
Two next-stage components are specified but not implemented.
First, the selected route can be exposed to YOPO as a chain of overlapping
safe regions sampled along the witness, rendered into the depth image by
ray--sphere intersection as a two-channel corridor mask
\begin{equation}
 M_t(u)=\left[
 \frac{\min\mathcal{I}_u}{d_{\max}},
 \frac{\max\mathcal{I}_u}{d_{\max}}
 \right],
\label{eq:corridor_mask}
\end{equation}
so the policy input becomes $[D_t,M_t]$ without changing the backbone, while
depth remains the dominant collision signal.
Second, a model-independent semantic observation contract
\begin{equation}
 \mathcal{Z}_t=\{(\Omega_m,s_m,c_m,t_m)\}_{m=1}^{M}
\label{eq:semantic_contract}
\end{equation}
lets a larger VLM such as Qwen3-VL replace PEARL: an adapter rasterizes
boxes, points, or masks into the same heatmap that the projection, EMA, and
edge-risk equations consume unchanged.
Both extensions preserve three invariants: only measured geometry determines
collision validity, every learned signal has a zero-input fallback, and all
asynchronous evidence carries a timestamp and bounded lifetime.
Claims about corridor conditioning or large-VLM accuracy will be added only
after the corresponding implementations and paired experiments are complete.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{CONCLUSION}
ScaleNav introduces semantic foresight at the topological route layer.
Depth-clipped open-vocabulary observations become persistent far-field
semantic nodes.
Their continuous field acts on collision-free witness paths and can change a
branch before the risk is geometrically observed.
A world-frame witness memory preserves route identity as the graph is replaced
asynchronously.
The unchanged YOPO policy receives only depth and a rolling relative goal.
This yields a distinct separation: topology remembers, semantics ranks, and
the local policy flies.
The planned corridor interface will widen the memory passed to the local
policy, while the planned Qwen3-VL adapter will widen the language capability
without changing the planner contract.
