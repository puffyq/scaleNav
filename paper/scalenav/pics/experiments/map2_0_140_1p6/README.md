# Map2 Single-Run Validation

This directory contains a pipeline validation at the fixed Map2 mission:

- start: `(0.0, 0.0, 1.6)` m
- goal: `(0.0, 140.0, 1.6)` m
- goal radius: `0.5` m
- admissible arrival speed: `0.3` m/s
- date: 2026-08-28

`single_run_metrics.csv` is based on synchronized 100 Hz odometry and contains
one goal-reaching YOPO run and one goal-reaching ScaleNav run. It is not the
final 20-trial paired benchmark and must not be used to claim aggregate success
rates. Because the renderer had `ignore_collision: true`, safety and collision
rates are marked `N/A` rather than inferred from the collision topic.

EGO-Planner and SUPER now have ROS2 Map2 adapters under
`bc/third_party/compare/`. Both official aerial planners build locally and use
the same simulator, RGB-D stream, odometry, dynamic limits, collision handling,
and `(0, 140, 1.6)` m goal. Their rows remain unreported until matched
collision-enabled flights are recorded; no values are inferred from adapter
smoke tests.

Artifacts:

- `scalenav_rviz.png`: full RViz capture with the ScaleNav graph and trajectory
- `scalenav_rviz_trajectory_paper.png`: cropped ScaleNav RViz trajectory view
- `yopo_rviz.png`: full RViz capture of the YOPO trajectory
- `yopo_rviz_trajectory_paper.png`: cropped YOPO RViz trajectory view
- `trajectory_speed_comparison.{png,pdf}`: speed-colored comparison with one
  row per external planner above the ScaleNav row and one shared colorbar

Raw logs:

- `bc/log_event/run_yopo_map2_actual_20260828/`
- `bc/log_event/run_scalenav_map2_actual_20260828/`

The comparison plot is generated by `paper/scalenav/plot_speed_trajectories.py`.
Its `--baseline LABEL=JSONL` option is repeatable, so EGO-Planner and SUPER can
be added when matched closed-loop logs become available.
